# Project Implementation Screenshots
# Written by Brian McCarthy

This directory contains placeholders for the 9 project tasks. 
To obtain high-fidelity PNG screenshots with simulated terminal/UI inputs and outputs:

1. Launch the application.
2. Click the "**Download Deliverables**" button in the top navigation bar.
3. Select each task in the sidebar.
4. Click "**Download Deliverable PNG**".

The following files are mapped to the tasks:
1. product_details_deploy.png
2. dealer_details_deploy.png
3. git_clone.png
4. index_urlchanges.png
5. frontend_deploy.png
6. homepage.png
